## Root causes and changes

| Area | Source change and resulting behaviour |
| --- | --- |
| DHCP/configuration | `first-run.cjs` now validates an installed configuration with the guarded current-lease resolver. Previously the GUI refused Start before the already-fixed host was reached. New settings record the adapter MAC (when available) and mask; old settings are read without rewriting. Wrong adapter, hardware identity, mask, subnet, model and TV conflicts fail closed. |
| Old status panel | `TVControls.cs` no longer reads saved `network.localIp` or independently probes that address. It verifies the owned scheduled-task action and uses the same `status-session.cjs` as the standalone app. Its script path matches the documented Control-Panel layout. The task runner's accidental PowerShell `$profile` path and obsolete exact 88-file check are corrected in source only. |
| Live status | The supervisor records its selected adapter/current address/TV and passes a non-secret run ID to both services. Status probes only the validated current local address, with a deadline, bounded response and no redirects; both services must match the run and expected service type. A saved `ready` record, dead PID, unrelated service, stalled source or changed selection cannot produce a healthy status. Startup acknowledgement is bounded. Startup errors and pending audio restoration remain visible. |
| TV playback | A token-protected diagnostic heartbeat accepts bounded media state only from the selected TV IP. It distinguishes advancing video from buffering, paused/hidden pages, error and absent reports. Neither the heartbeat nor its status grants mouse permission or changes audio. GUI minimisation requires confirmed advancing playback. This reports browser telemetry, not independent proof of pixels on a physical display. |
| Discovery | Both GUIs provide explicit network selection. First-run auto-discovery occurs only with one available NIC. Invalid saved-network settings cannot silently fall back to another NIC. The old scanner uses the correct Node UDP socket options. Socket failures are reported instead of being presented as successful empty scans. LG AirPlay announcements remain recognisable as LG; another brand at the saved IP is not relabelled supported/connected. |
| Start/Stop | All local IPv4/IPv6 TV listeners are checked before startup/recovery. An installation-specific local pipe serialises starts and is released by Windows on process exit, with no persistent crash lock. Stop is scoped to the session ID and independent of network resolution/encoder settings. The GUI remains responsive during bridge operations, drains both process streams and has bounded waits. |
| Audio | Selecting audio and confirming Start explicitly authorises on-demand per-user audio-guardian setup in the shipped GUI. The guardian has no automatic triggers and refuses another installation's task. Normal uninstall removes only its own inactive guardian; other installations' tasks are preserved. None of these task-management paths were invoked against the real owner account during QA. |
| Install/uninstall | Test mode now requires a marked random directory under TEMP/ImAccessibility-QA, instead of hard-coding the working installation's tree. Uninstall rejects directory links, active/uncertain state, pending Stop/audio, executing installed applications, unrecognised and modified files. User settings are preserved. Registry deletion is conditional on matching InstallLocation. |
| Package evidence | The builder copies only verified manifest entries. It emits hashes/versions/licence hashes in `THIRD_PARTY/bundled-runtimes.json`. The auditor validates this inventory and no longer reports the unrelated GPL vendor's dependency counts as evidence for the LGPL binary. `readyForPublicDistribution:false` remains unconditional. |

A real publisher signature, timestamp and verification are required before release acceptance; even signing does not itself prove SmartScreen reputation. 6. **Physical/accessible packaged acceptance:** exercise this exact packaged build on the supported LG, including first pairing, DHCP renewal/relaunch, long video/audio, Stop during startup, reconnect, speaker restoration, Narrator/NVDA, DPI/high-contrast/keyboard navigation, Windows 11 and a genuine clean Windows-user install/uninstall. Windows Server CI does not substitute for Windows 11 or TV acceptance.
7. **Remaining product boundaries:** settings intentionally do not silently switch to another TV/network. Legacy settings have no MAC/mask fingerprint. Even new MAC/subnet pins do not identify a Wi-Fi SSID or Windows network-profile GUID, so roaming to a different network with identical addressing remains unverified. A guided migration/re-pair workflow for replacing an existing TV/network is not implemented by this change. Unsupported TVs remain discovery-only; supported model is OLED55CX6LA. These limits must be resolved or explicitly scoped before describing the product as universally self-service.
