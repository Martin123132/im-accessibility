# Security policy

I’m-accessibility is a **private experimental preview**, not a hardened internet remote-desktop product.

Please read [Security and privacy](docs/SECURITY.md) for the actual boundaries, consent model and unreleased security requirements.

Report security concerns through a private channel to the repository owner. Do not publish active credentials, pairing links, private session recordings or exploit details in a public issue.

The frozen v0.1.0 source checkpoint is preserved for reproducibility; no blanket security-maintenance guarantee is made for that tag.
